# Isle 2.3.0 — CN / Global compatibility

Isle brings supported notifications and app events into HONOR Magic Capsule on MagicOS.

## What's new
- Automatic identification of **CN / Global** HONOR SystemUI variant at app launch.
- Preserved existing Magic Capsule behavior on Chinese firmware.
- Global-specific notification payload compatibility: non-empty secondary text, adjusted large icon handling, and fallback tap action when an original action cannot be found.
- Existing Isle 2.2.5 functions and settings retained.

## Installation
- Download **Isle-2.3.0-RELEASE.apk** from the Assets section once attached.
- Package: `dev.haradreamer.capsule`
- Version: **2.3.0** (`versionCode 230`)
- Android 10+ (`minSdk 29`).
- Install over an earlier official Isle signed with the same certificate to retain settings.

## Compatibility
Test basis: HONOR Magic9 Pro Max CN (WKL-AN20) and HONOR Magic8 Pro Global (BKQ-N49), MagicOS 11 / Android 17. Features may vary with firmware and source apps.

## Feedback
Please report your model, exact MagicOS version, CN/Global variant, and whether native capsules expand properly, display full text and open the expected app when tapped.
