# Isle 2.2.5 — GitHub Release Notes

**Isle 2.2.5** — HONOR Magic Capsule notification and ongoing-event enhancements.

### Features
- Notification and event handling for supported messaging, navigation, call, timer, alarm and download sources.
- Magic Capsule integration, customizable appearance, animations and app selection.
- Multilingual interface: Russian, English, Simplified Chinese, Spanish, Brazilian Portuguese, Arabic, Turkish and Indonesian, plus system language.

### Build verification
- Production build dated 19 November 2026 from private branch `release/isle-2.2.5`.
- CI checks passed: project structure, regression tests, translation audit, Android lint, resource shrinking, minified release assembly.
- Application ID: `dev.haradreamer.capsule`; versionCode: `225`; versionName: `2.2.5`.

### Installation
1. Download the **signed** `.apk` from the Assets section below.
2. Install it and grant permissions requested for your enabled features.
3. When upgrading, the installed APK must have the same signing certificate; otherwise remove the older installation after backing up settings.

**Compatibility:** Primarily tested on HONOR Magic9 Pro Max (WKL-AN20), MagicOS 11. Other models and firmware are not guaranteed and need community testing.
